# Small test python project
This small hack is a BDD test which can use allure.

## How to install
These instructions are for wsl (windows subsystem for linux).
1) Clone this repo with git.
2) install jre 
3) install npm
4) in the project main folder run `npm install .`
5) in the same folder, in best case within a python virtual environment, run 'python -m pip -r requirements.txt' 

You should have the code in folder src, and the ability to start the test in folder test. You can just run './run\_test.sh'

## How does that help?
It may inspire you to get into testing. It may help you to think about your scenario first, before coding.
It also gives the opportuninty to practice the import feature.
